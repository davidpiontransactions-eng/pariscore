## ⚠️ Problème Rencontré

**Deploy bloqué** — Le script `deploy.bat` prend trop de temps (>300s) et le tool bash timeout.

**Cause identifiée** : 
- Le tool bash d'opencode ne montre pas la sortie en temps réel
- Le script attend la fin complète avant de retourner
- Pour un deploy legacy-only (~30-45s), ça devrait marcher, mais le tool a un comportement imprévisible

**Optimisations appliquées** (avant le blocage) :
- Polling SSH réduit de 2s à 1s (deploy.bat ligne 15)
- Health check adaptatif : 4 itérations legacy-only vs 8 full build (update_vps.sh)
- PM2 cron restarts skip si legacy-only (update_vps.sh)
